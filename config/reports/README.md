# 報告的 Word 樣式模板（可選）

把一份 Word 文件存成這個文件夾裡的 `template.docx`，導出的 Word 報告就以它為底：

- 字體：改「內文」（Normal）樣式的中英文字體和字號
- 標題：改「標題」（Title）和「標題 1–3」（Heading 1–3）樣式
- 表格：改「表格格線」（Table Grid）樣式
- 頁邊距、紙張大小、頁眉（公司抬頭、logo）、頁腳（頁碼）：直接在文件裡設

模板裡原有的正文會保留在報告最前面，所以模板的正文部分請留空。
沒有這個文件時用內置樣式（微軟正黑體，頁腳帶頁碼）。不要放任何含密鑰或內部聯繫方式的內容進去：它會跟着配置一起進 git。
